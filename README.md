Обувной
Цель приложения
Программа создана для ознакомления с ассортиментом и совершения покупок в обувном магазине.
Подготовка к работе
До первого запуска требуется выполнить ряд действий:
Активировать Open Server.
Включить службу MySQL.
Загрузить базу данных через файл database.sql.
Проверить правильность настроек соединения с базой.
Как запустить программу
Перейдите в директорию с приложением и запустите исполняемый файл Магазин обуви.exe. После этого авторизуйтесь в системе либо воспользуйтесь опцией «Войти как гость».
Возможности в зависимости от статуса пользователя

Гость
Просмотр каталога.
Поиск моделей обуви.
Применение сортировки и фильтров.

Зарегистрированный покупатель
Просмотр товаров.
Оформление покупок.
Доступ к истории собственных заказов.

Менеджер
Управление номенклатурой и заказами.
Использование поиска, фильтрации и сортировки.

Администратор
Добавление, корректировка и удаление позиций из каталога.
Полный контроль над заказами.
Примечание: для редактирования записи нужно кликнуть по ней правой клавишей мыши, а для удаления — выполнить двойной щелчок.

Технологический стек
Проект разработан на Python с использованием PyQt6, для работы с базой данных задействованы СУБД MySQL и PyMySQL.
